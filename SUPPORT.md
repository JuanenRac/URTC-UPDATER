# Support Information 🛠️ (URTC-UPDATER)

Thank you for using URTC-UPDATER! Here is how you can get help:

## 📺 Video Tutorials & Demos
The official YouTube channel covers the ecosystem's tools:
[youtube.com/@electrohobby3d](https://youtube.com/@electrohobby3d)

## ✉️ Direct Technical Inquiries
For questions about installing, updating or restoring a repository:
Email: `electrohobby3d@gmail.com`

## 🐛 Bug Reports
If you found a defect, please open a **GitHub Issue** in this repository with the output of `urtc-updater --cli status` and the log file of the window (under `~/.urtc_updater/logs`), without tokens or private paths.
*Please search existing issues before opening a new one.*

## ❌ What is NOT support?
- Problems of one of the repositories it installs belong in that repository.
- Please do not use Issues for "How to" questions.
